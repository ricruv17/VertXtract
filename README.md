
# VertXtract
![VertXtract Logo](drawing.png "Title")


Program to process and plot `.VERT` files generated by Createc's STMAFM software.




# Installation
The easiest way is to download and install the latest release, otherwise you may use Conda.

First, make sure you have **Conda** installed on your computer.
Then download the files from this repository and place them in a folder of your choice.
Open a Conda prompt in that folder and run: 

```powershell
conda env create -f vertxtract.yml
```
# Usage
Open the software and load a folder from the GUI. Make sure the folder contains 1 `.DAT` file with 2D information, and the `.VERT` files you wish to analyze.

If you are using conda you may run the software like this:

```powershell
conda activate vertxtract
python vertxtract.py 
```
