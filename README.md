# VERTXtract
Program to process and plot `.VERT` files generated by Createc's STMAFM software.

# Installation
First, make sure you have **Conda** installed on your computer.
Then download the files from this repository and place them in a folder of your choice.
Open a Conda prompt in that folder and run: 

```powershell
conda env create -f vertxtract.yml
```

# Usage
Open a Conda prompt in the folder where you placed the downloaded files and run: 

```powershell
conda activate vertxtract
python main_viewer.py "\FolderWithFiles\"
```

Make sure the folder contains 1 `.DAT` file with 2D information, and the `.VERT` files you wish to analyze.
